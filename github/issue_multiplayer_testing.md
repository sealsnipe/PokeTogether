# Multiplayer-Testing

## Beschreibung

Es wurden verschiedene Testskripte implementiert, um die Multiplayer-Funktionalität zu testen, insbesondere die Synchronisierung der Spielerpositionen.

## Implementierte Testskripte

- `test_local_multiplayer.py`: Testet die grundlegende Multiplayer-Funktionalität
- `test_position_sync.py`: Testet die Synchronisierung der Spielerpositionen
- `test_position_sync_simple.py`: Vereinfachter Test für die Spielerposition-Synchronisierung

## Testergebnisse

Die Tests zeigen, dass die Clients erfolgreich mit dem Server verbunden werden können, aber es gibt noch Probleme bei der Extraktion der Spielerpositionen aus den Logs.

## Screenshots

Die Screenshots der Tests befinden sich im Verzeichnis `test_screenshots`.

## Verbesserungsmöglichkeiten

- Verbesserung der Logging-Funktionalität
- Implementierung eines strukturierten Testberichts
- Verbesserung der Testabdeckung
- Automatisierung der Tests

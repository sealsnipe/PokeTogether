# Pallet Town (Alabastia)

Diese Verzeichnis enthält die Karte für Pallet Town (Alabastia), die erste Stadt in Pokémon Red/Blue.

## Dateien

- `pallet_town.tmx`: Die Tiled-Karte für Pallet Town
- `pallet_town.png`: Ein Bild der Karte (muss manuell heruntergeladen werden)

## Hinweise

Die Karte basiert auf der originalen Pallet Town aus Pokémon Red/Blue. Sie enthält die folgenden Elemente:

- Das Haus des Spielers
- Das Haus des Rivalen
- Das Labor von Professor Eich
- Wege und Gras
- Zugänge zu Route 1

## Verwendung

Die Karte kann mit dem Tiled Map Editor bearbeitet werden. Sie kann auch direkt in das Spiel geladen werden, indem die `TiledMap`-Klasse verwendet wird.

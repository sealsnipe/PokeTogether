# Pokémon Red/Blue Tilesets und Karten

Diese Verzeichnis enthält Tilesets und Karten aus Pokémon Red/Blue, die für das PokeTogether-Projekt verwendet werden.

## Quellen

Die Bilder stammen von The Spriters Resource:
- [Pallet Town](https://www.spriters-resource.com/game_boy_gbc/pokemonredblue/sheet/55181/)
- [Tileset](https://www.spriters-resource.com/game_boy_gbc/pokemonredblue/sheet/63033/)

## Verwendung

Diese Bilder werden als Referenz für die Erstellung der Karten in unserem Spiel verwendet. Sie können auch direkt als Texturen für die Tilemap-Klasse verwendet werden.

## Hinweis

Die Bilder müssen manuell von den oben genannten Quellen heruntergeladen werden, da wir keinen direkten Zugriff auf die Bilder haben.
